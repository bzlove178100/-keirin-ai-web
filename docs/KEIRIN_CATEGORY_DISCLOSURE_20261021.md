## 目的と仕様の確認範囲

会員用の商品画面へ進む前に、指定されたカテゴリだけをサーバー応答へ含める処理と表示を確認する。
全候補をブラウザへ送ってからCSS等で隠す方式にはしない。既存5カテゴリは維持する。

2026-10-21に過去会話検索で確認できたのは、2026-10-03の既存5カテゴリ＋最上位FINAL 5＋
全会員向けDREAM TICKETの採用方針。DREAM TICKETは超大穴以上で根拠が強い時のみ。
検索結果は元会話全文ではない。無料/各有料段階の細かなカテゴリ割当はassistant提案として返り、
その表の本人による明示採用は確認できない。価格、期限、owner/admin、日/会場パス、失効条件を推測しない。

今回は会員プラン表を作らず、カテゴリ名の明示集合を入力にする合成テスト契約を追加する。
「1/2/3/全5カテゴリ」は試験入力であり、無料/有料商品の階層を決定したものではない。
FINAL 5/DREAM TICKETの買い目生成、価格、購入、会員権付与はこの候補に含めない。
現在のowner専用Web/API、Auth/profile、RLS、Functionソース/配備は変更しない。

## サーバー側の投影

`ml.product_category_preview.category_view` は固定予測と合成指定を受け取る読取専用関数。
合成指定は次の完全一致キーのみを受け付ける。

- schema_version = synthetic-category-fixture-v1
- synthetic_only = true
- snapshot_id = 対象予測の32桁hex ID
- categories = 既存5カテゴリ名の重複しない配列
- starts_at / ends_at = timezone付き日時、starts_at < ends_at

指定なし/空配列は候補なし。対象ID不一致、開始前、期限ちょうど以降も候補なし。
開始時刻ちょうどは表示対象。未知カテゴリ、FINAL5/DREAM_TICKET、重複、余分なrole/plan、
非合成指定、不正日時/範囲は拒否し、全カテゴリへフォールバックしない。
これはこの合成契約の境界であり、日パス等の商品の期限規則を決定していない。

表示対象なら既存model_web_response/validate_snapshotを通し、許可されたカテゴリの
既存候補・順位・未校正確率・確認済みodds・注記だけをコピーする。未知oddsはnullのまま。
結果・全確率表・生snapshot・モデルファイル・認証情報・対象外カテゴリの候補を返さない。
カテゴリ順は既存5カテゴリ順。候補不足を補完せず、件数は実際の返却候補から計算する。
除外時はrace/予測ID/時刻も応答へ加えず、空categories/候補0と理由だけを返す。

全応答はsynthetic_only=true、authentication_status/entitlement_status=not_asserted。
実取得/実学習/DB書込/本番予想/課金/金銭EVはfalse。実ユーザーの権利を確認する関数ではない。
本番APIへ流用する際は信頼できるサーバー側の本人認証・利用権取得・対象範囲判定が別途必要。
呼出側持込みのcategories/role/planを実認可へ採用してはならない。

## ローカル合成画面

合成予測画面の「カテゴリ別の表示を合成確認」から `/category-view/<snapshot-id>` を開く。
表示指定なし、的中のみ、2カテゴリ、3カテゴリ、全5、期限切れ、開始前、別予測を選択できる。
`GET /api/category-view/<snapshot-id>/<scenario>` はサーバーの固定ケースだけを生成する。
任意grant/JSON/planは受け付けず、未知scenarioは409、不正path/queryや存在しないIDは404。
既存loopback/Host/Origin/CSP/no-store/nosniffを維持。書込・モデル学習・外部通信は行わない。

誰でも全ケースを選べる開発画面であり、ローカルサーバーの既存全件exportも利用できる。
この画面やcase選択を認可境界と呼ばず、会員サービスとして公開しない。
各通常ケースの時刻はその要求時点を基準に作る試験値。実際の会員期間や失効状態を保持しない。

切替直後に前の候補を消す。遅れて届いた古い応答は捨て、最新の選択だけを描画する。
通信/応答検証の失敗でも前の候補を残さず、再確認ボタンから明示再読込する。
レース/カテゴリ/候補/注記はtextContentで描画する。保存済み予測と確認一式は変更しない。
